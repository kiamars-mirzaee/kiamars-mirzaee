## 📦 Open source

**[kiamars-mirzaee/NetGrid](https://github.com/kiamars-mirzaee/NetGrid)**

![.NET](https://img.shields.io/badge/.NET-8.0-512BD4) ![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

A reusable, backend-agnostic data grid engine for ASP.NET Core — search, dynamic filtering, sorting, pagination, and batched Excel export, all driven from a single `IQueryable<T>` source, with an optional Hangfire-backed background export flow for large datasets. Designed as the .NET counterpart of a mature Laravel/PHP grid component used in production.

```bash
git clone https://github.com/kiamars-mirzaee/NetGrid.git
```

**[kiamars-mirzaee/elasticsearch-eloquent](https://github.com/kiamars-mirzaee/elasticsearch-eloquent)**

[![Packagist](https://img.shields.io/packagist/v/kiamars-mirzaee/elasticsearch-eloquent?style=flat&logo=packagist&logoColor=white)](https://packagist.org/packages/kiamars-mirzaee/elasticsearch-eloquent)

Eloquent-style interface for Elasticsearch in Laravel. Brings familiar Active Record patterns to search indexing and querying.

```bash
composer require kiamars-mirzaee/elasticsearch-eloquent
```
